# Projeto de tradução de obras

Repositório de traduções literárias para o português brasileiro. Cada obra fica em uma pasta própria, com seus textos, fontes e decisões editoriais.

## Obras

| Obra | Versão | Acompanhamento |
| --- | --- | --- |
| [Re:Zero](ReZero/README.md) | Web novel | [Capítulos e revisões](ReZero/ACOMPANHAMENTO.md) |

## Adicionar uma obra

Crie uma pasta na raiz com o nome da obra e inclua-a no índice acima. Registre no README da obra a versão traduzida, as fontes e como consultar capítulos e revisões. Quando houver glossário, guia de estilo ou ferramentas próprias, mantenha-os na pasta da obra.

As orientações editoriais compartilhadas estão em [AGENTS.md](AGENTS.md). Para Re:Zero, consulte também o [guia da obra](ReZero/AGENTS.md) e as instruções de uso do [verificador](ReZero/README.md#conferência-automática).
